# AC-07 · Historique d'un quartier sur 30 jours

| Difficulté | Branche | Tests à compléter |

## Contexte

Les habitants veulent savoir si leur quartier est souvent touché : combien de coupures sur les 30 derniers
jours, et combien de temps au total, séparément pour l'eau et pour l'électricité. Les données de
démonstration contiennent un historique pour Angré, Niangon, PK 18 et Remblais, dont quelques coupures de
plus de 30 jours qui ne doivent pas être comptées.

## Critères d'acceptation

- [ ] Une page publique `/quartiers/{id}/historique` est accessible depuis le nom de chaque quartier dans la liste ; un quartier inconnu renvoie une erreur 404.
- [ ] Pour chaque type (eau, électricité) : le nombre de coupures commencées dans les 30 derniers jours.
- [ ] Pour chaque type : la durée cumulée, au format « 26 h 15 min » ; une coupure encore en cours compte jusqu'à maintenant.
- [ ] Les coupures commencées il y a plus de 30 jours ne sont pas comptées.
- [ ] La page liste aussi les coupures de la période (date de début, type, durée, statut), de la plus récente à la plus ancienne.
- [ ] Le calcul est dans une classe dédiée (par exemple `App\Services\NeighborhoodHistory`) testée avec une date figée.

## Indices

- Une seule requête : `$neighborhood->incidents()->where('started_at', '>=', now()->subDays(30))->get()`, puis `groupBy(fn ($incident) => $incident->type->value)`.
- Durée d'une coupure : `$incident->started_at->diffInMinutes($incident->resolved_at ?? now())`.
- Figez la date dans les tests : `$this->travelTo(Carbon::parse('2026-10-15 12:00'))`.
