# AC-06 · Notifications SMS des abonnés via la file d'attente

## Contexte

Les abonnés d'un quartier veulent être prévenus dès qu'une coupure y est confirmée. Une coupure est
« confirmée » quand elle réunit des signalements de 3 téléphones différents (règle du ticket AC-04 ; si elle
n'existe pas dans votre copie, ajoutez une colonne `confirmed_at` et une petite classe qui l'applique).

Envoyer des SMS à des centaines d'abonnés peut être lent : l'envoi se fait en arrière-plan, par la file
d'attente de Laravel (« queue »), et un abonné ne doit jamais recevoir deux fois l'alerte d'une même coupure.
Il n'y a pas de vrai fournisseur : les SMS sont simulés.

## Critères d'acceptation

- [ ] Quand une coupure devient confirmée, un événement `IncidentConfirmed` est déclenché une seule fois.
- [ ] Un job en file d'attente (`ShouldQueue`) envoie un SMS simulé à chaque abonné du quartier : « Alerte Coupures : coupure d'électricité confirmée à Angré (Cocody). »
- [ ] Les SMS simulés passent par une interface `SmsSender` et un faux fournisseur qui les enregistre dans une table `sms_messages` (téléphone, message, coupure, date).
- [ ] Un abonné reçoit au plus un SMS par coupure, même si le job est exécuté deux fois.
- [ ] Les abonnés des autres quartiers ne reçoivent rien.
- [ ] Les tests vérifient la mise en file avec `Queue::fake()` et l'envoi en exécutant le job ; le README explique comment lancer `php artisan queue:work` en local.

## Indices

- `php artisan make:event IncidentConfirmed`, `php artisan make:job NotifySubscribers`, et un écouteur ou un appel direct `NotifySubscribers::dispatch($incident)`.
- La base de démonstration utilise déjà `QUEUE_CONNECTION=database` : les jobs attendent dans la table `jobs` jusqu'à `php artisan queue:work`. Les tests utilisent `QUEUE_CONNECTION=sync` (voir `phpunit.xml`).
- Unicité : contrainte `unique(['incident_id', 'phone'])` sur `sms_messages`, et vérification avant l'envoi (idempotence).
- Liaison de l'interface dans `AppServiceProvider::register()` : `$this->app->bind(SmsSender::class, FakeSmsSender::class);`.
- Créez les signalements de test directement avec les factories : `Report::factory()->for($incident)->create(['phone' => ...])`.
