# AC-08 · Export CSV des coupures pour le modérateur

| Difficulté | Branche | Tests à compléter |

## Contexte

Le modérateur transmet chaque mois un état des coupures à la mairie, qui l'ouvre dans Excel. Il a besoin
d'exporter au format CSV les coupures d'une période choisie.

## Critères d'acceptation

- [ ] Dans l'espace de modération, un formulaire « Exporter » demande une date de début et une date de fin.
- [ ] `GET /moderation/export?du=2026-10-01&au=2026-10-15` télécharge le fichier `coupures-2026-10-01-au-2026-10-15.csv`.
- [ ] Colonnes : identifiant, type, commune, quartier, statut, début, fin, durée en minutes, nombre de signalements ; séparateur point-virgule, encodage UTF-8 avec BOM pour qu'Excel affiche correctement les accents.
- [ ] Seules les coupures commencées pendant la période (bornes incluses, journée de fin entière) sont exportées.
- [ ] Les dates sont obligatoires et la fin ne peut pas précéder le début (messages d'erreur clairs).
- [ ] L'export est réservé aux modérateurs : un visiteur non connecté est renvoyé vers la connexion.

## Indices

- `response()->streamDownload(function () { ... }, $nomDuFichier, ['Content-Type' => 'text/csv; charset=UTF-8'])` et `fputcsv($flux, $ligne, ';')` sur `php://output`.
- Le BOM UTF-8 s'écrit en premier : `echo "\xEF\xBB\xBF";`.
- Parcourez les coupures avec `->lazy()` pour ne pas tout charger en mémoire, et `withCount('reports')`.
- Dans les tests : `$response->assertDownload('coupures-2026-10-01-au-2026-10-15.csv')` et `$response->streamedContent()` pour lire le contenu.
