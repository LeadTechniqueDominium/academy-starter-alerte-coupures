# AC-05 · Anti-abus : 3 signalements par téléphone et par heure

| Difficulté | Branche | Tests à compléter |
| --- | --- | --- |
| intermédiaire | `ticket/AC-05` | `tests/Feature/Tickets/AC-05Test.php` |

## Contexte

Un plaisantin peut inonder la carte de faux signalements. Règle : au plus 3 signalements par numéro de
téléphone sur une heure glissante (les 60 dernières minutes). Au-delà, le formulaire refuse l'envoi avec un
message clair qui indique quand réessayer.

## Critères d'acceptation

- [ ] Le 4e signalement d'un même téléphone en moins d'une heure est refusé avec le message « Vous avez déjà envoyé 3 signalements dans la dernière heure. Réessayez dans X minutes. » ; rien n'est enregistré.
- [ ] X est le nombre de minutes avant que le plus ancien des 3 signalements sorte de la fenêtre d'une heure (au moins 1).
- [ ] La fenêtre est glissante : une heure après le premier signalement, un nouvel envoi est accepté.
- [ ] Deux téléphones différents ont chacun leur propre limite, et « 07 08 11 22 33 » et « 0708112233 » sont le même téléphone.
- [ ] Après un refus, le formulaire conserve les champs déjà saisis.
- [ ] La règle est une règle de validation dédiée (par exemple `App\Rules\MaxReportsPerHour`) avec la limite (3) et la durée (60 minutes) en constantes, testée unitairement.

## Indices

- `php artisan make:rule MaxReportsPerHour` crée une classe avec une méthode `validate()` ; utilisez-la dans `StoreReportRequest`.
- Le téléphone est déjà normalisé dans `prepareForValidation()` : la règle reçoit `0708112233`.
- Comptez avec `Report::query()->where('phone', $phone)->where('created_at', '>=', now()->subHour())->count()`.
- Testez le temps qui passe avec `$this->travel(61)->minutes();`.

## Fichiers concernés

- `app/Http/Requests/StoreReportRequest.php` (à modifier)
